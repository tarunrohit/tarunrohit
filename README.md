### What I'm building

I'm a Software Development Engineer at **Winjit Technologies**, working across full-stack product delivery and agentic AI systems. Day to day that means integrating LLMs (Gemini, Claude) into real products, building multi-agent tooling on MCP and A2A protocols, and using AI-assisted / "vibe coding" workflows to ship production apps fast — recent examples include a full e-commerce app UI delivered in ~3 weeks and a CMS UI shipped across 9 sprints in 15 days, both via Figma-to-code automation.

On my own initiative I also designed and built **FSD Synthesis**, an internal multi-agent R&D platform at Winjit that orchestrates 33 expert agents to auto-generate architecture diagrams, use cases, and project breakdowns from a single spec.
